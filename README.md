About the Internship

This repository contains the five Python programming tasks completed as part of my CodSoft Python Programming Internship. These projects helped me improve my Python programming skills, logical thinking, and problem-solving abilities.

Tasks Included

Task 1: To-Do List

Description: A simple task management application that allows users to organize their daily activities.

Features:

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks

Technology: Python

Task 2: Calculator

Description: A basic calculator that performs arithmetic operations based on user input.

Features:

- Addition
- Subtraction
- Multiplication
- Division
- User-friendly input and output

Technology: Python

Task 3: Password Generator

Description: A password generator that creates random passwords to help users improve password security.

Features:

- Generate random passwords
- Customize password length
- Include letters, numbers, and special characters

Technology: Python

Task 4: Rock-Paper-Scissors Game

Description: A command-line game where the user plays Rock-Paper-Scissors against the computer.

Features:

- User selects rock, paper, or scissors
- Computer makes a random choice
- Displays the winner
- Allows users to play multiple rounds

Technology: Python

Task 5: Contact Book

Description: A contact management application that allows users to store and manage contact information.

Features:

- Add new contacts
- View saved contacts
- Search for contacts
- Update contact details
- Delete contacts

Technology: Python

Technologies Used

- Python 3
- Python standard libraries
- Git and GitHub

How to Run the Projects

1. Install Python on your computer.

2. Clone this repository:
   
   git clone https://github.com/moodsreeram123/CODSOFT_TASKNO.git

3. Open the downloaded project folder.

4. Navigate to the task folder you want to run.

5. Run the relevant Python file:
   
   python filename.py
   
   Replace "filename.py" with the actual Python filename in that task folder.
